# Basic Programming language operations :

- Store information (variables)
- make decisions (if-else)
- repeat actions (loops)
- calculate things (operators)

## Important rules in python :

- Syntax (spacing we use to seperate blocks of code and to bundle pieces of code)
- Indentation (it doesn't have curly braces like CPP)

## variables

- used to store information
- name = "rajat"

## comments :

- used '#' for comments
- use """ """ for multiline comments
- good comments are those which explains WHY, not WHAT

## datatypes :

- kinds of data we can define and store in python
- Integers (whole number without decimals)
- Floats (numbers with decimal points)
- Strings
- Boolean

## Strings

- text
- text based operations
- replace, lowercase, uppercase, title case, strip extra spaces, find, count

## Operators

- arithmetic (basic math operations)
- assignment (assign or updates variable values)
- comparison (compares values and returns a boolean)
- logical (combines and evaluates conditional statements)
- bitwise (perform bit-by-bit operations on binary numbers)
- identity {is, is not} (check if two var point to the same object in memory)
  - x is y
- membership {in, not in} (checks if a value exists within a sequence [list,tuple,string])
  - 'a' in 'apple'

## Control flow :

- if, else
- if,elif,else
- for in in range(1:10)
- for i in range(10)
- for in in range(1,10,2)
